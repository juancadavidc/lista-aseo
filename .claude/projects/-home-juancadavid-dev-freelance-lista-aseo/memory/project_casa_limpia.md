Casa Limpia es una app mobile-first para coordinar limpieza del hogar.
- **Stack:** React 18 + Vite (frontend), Express.js (backend), PostgreSQL 16
- **Auth:** better-auth con plugin de organizaciones (casas)
- **Deploy:** Docker Compose con Nginx
- **Dominio:** Tareas con frecuencia inteligente, productos, lista de compras
- **Multi-tenant:** Cada casa es una organización aislada

**Why:** Proyecto freelance activo con despliegues reales.
**How to apply:** Todo desarrollo debe respetar la arquitectura existente y el aislamiento por casa.
